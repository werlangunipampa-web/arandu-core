## Scope

ARANDU/Aurora-ACA investigates whether selected functional dynamics inspired by Ausubelian meaningful learning can be implemented in a computational substrate. The project distinguishes persistent memory from historically acquired structure and asks whether prior acquisition can causally change later learning.

This artifact deliberately preserves positive, negative, technically inconclusive, and post-hoc development evidence. It must not be read as a success-only reconstruction of the project.

## Public / private boundary

This public tree contains manuscript pointers, public scoping-review materials, public/consumed experimental material, selected code required to inspect historical stages, test evidence, terminal evidence, and cryptographic manifests.

It intentionally excludes private gold, unexposed R5/R5-R confirmatory material, credentials/secrets, and historical archives that have not yet passed file-level artifact audit.

The omission of future blind assets is part of the experimental design, not a lack of reproducibility.

## Integrity principle

> Preserving the experimental history is more important than producing a narrative of success.

No later engineering repair retroactively changes the status of an earlier blind or historically frozen result.
