# Private evaluation material excluded

The original frozen R2 archive contains a `private_eval/` directory with gold data and future evaluation units. Those files are intentionally **not** included in the public artifact.

The omission is methodological, not accidental: public release should not establish a precedent of exposing blind-evaluation assets before the project decides they are safe to disclose.

The public corpus, protocol, source code, tests, preregistration note, manifests, and relevant documentation are suitable for release after file-level audit.
