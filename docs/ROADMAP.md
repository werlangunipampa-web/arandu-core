# Roadmap

## 0.1 — Three Rivers Core Foundation
- Core universal.
- Três rios.
- Intents.
- Perfis.
- APIs de plataforma e input.

## 0.2 — Input Abstraction Runtime
- Teclado.
- Mouse.
- Touchpad.
- Keymap configurável.
- Perfis persistentes.

## 0.3 — GNOME Adapter
- Conectar a extensão GNOME existente ao Core.
- D-Bus ou IPC equivalente.
- Remover lógica duplicada da extensão.

## 0.4 — Persistence
- SQLite local.
- Sessões de uso.
- Estatísticas históricas.
- Migrações de schema.

## 0.5 — Voice LAB
- ABERTOS.
- MEMÓRIA.
- FREQUENTES.
- PRÓXIMO / ANTERIOR / ABRIR / VOLTAR.

## 0.6 — Tonal Navigation LAB
- Grave / médio / agudo.
- Calibração individual.
- Limiar de confiança.
- Debounce e dwell time.

## 0.7 — Head Movement LAB
- Movimento de cabeça local.
- Calibração.
- Confirmação e cancelamento.

## 0.8 — Universal Shell
- Overlay cross-platform.
- Avaliação Slint/Tauri.

## 1.0
- Linux + Windows + macOS.
- Perfis multimodais.
- Documentação de acessibilidade.
